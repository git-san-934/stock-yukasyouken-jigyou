# このファイルは通常は編集不要です。
#
# scripts/update_all.py --all が EDINET から対象銘柄を自動収集するため、
# 証券コードを手で足す必要はありません（直近500日に有価証券報告書を出し、
# 証券コードを持つ提出者すべて＝約4,000社が対象）。
#
# 用途:
#   - 特定銘柄を除外したい: 行頭に - を付ける（例: -1234）
#   - --all を使わず少数だけ試す: 証券コードを 1 行ずつ（例: 285A）
#
# 例:
# 285A        # キオクシアHD だけ試すとき（--all なしで実行）
# -1234       # この銘柄は全件処理から除外
